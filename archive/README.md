# archive/

An archive is a record, not a bin.

| Directory | Contents |
|---|---|
| `phase0/` | Superseded Phase 0 material |
| `experiments/` | Retired experiments, retained with provenance |
| `superseded/` | Work replaced by later versions |
| `retired/` | Approaches abandoned, with the reason recorded |

## Rules

Every archived item retains: its original ID, its provenance, the reason for archival, the date,
and a pointer to the replacement work (or an explicit statement that there is none).

**Scientifically meaningful failed experiments are never deleted because they produced poor
results.** A valid experiment whose hypothesis was unsupported is evidence, and is retained and
reported — see the category distinction in `../experiments/failures/README.md`.

Nothing archived here has been removed from the experiment registry; registry entries change status
to `ARCHIVED` and keep their IDs.
